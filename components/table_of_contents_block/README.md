# Table of Contents Block

A block component that automatically generates a Table of Contents based on the h2 elements found on the page. The block scans the main page content and builds a list of anchor links pointing to the corresponding sections with scrollspy functionality.

## Overview

This component provides:

- Automatic generation of navigation links from page h2 headings
- Smooth scrolling to sections when clicking links
- Active state highlighting based on scroll position
- Sticky positioning for easy navigation
- Unique ID generation for each heading

## Usage

### Basic Usage

```twig
{% include 'mud_egov:table_of_contents_block' with {
  table_of_contents_block_label: 'Table of Contents',
  content: content,
  table_of_contents_block_uc: ['custom-class'],
} %}
```

### Using with Slots

```twig
{% embed 'mud_egov:table_of_contents_block' with {
  table_of_contents_block_label: 'On this page',
} %}
  {% block slot_content %}
    {# Custom content #}
  {% endblock %}
{% endembed %}
```

## Props

| Prop                            | Type         | Default | Description                                              |
| ------------------------------- | ------------ | ------- | -------------------------------------------------------- |
| `table_of_contents_block_label` | string\|null | null    | The block label/title displayed above the navigation.    |
| `content`                       | mixed        | -       | The block content (generated table of contents links).   |
| `table_of_contents_block_uc`    | array        | []      | An array of utility classes to add to the block wrapper. |
| `table_of_contents_block_att`   | Attribute    | -       | HTML attributes for the block element.                   |
| `title_attributes`              | Attribute    | -       | HTML attributes for the title element.                   |

## Slots

| Slot           | Required | Fallback  | Description                                |
| -------------- | -------- | --------- | ------------------------------------------ |
| `slot_content` | No       | `content` | The content slot for the navigation links. |

## JavaScript Behavior

The component includes JavaScript that:

1. Scans all h2 elements on the page (excluding those within `.table-of-contents`)
2. Generates unique IDs for each heading based on its text
3. Creates navigation links in the scrollspy container
4. Implements smooth scrolling when links are clicked
5. Updates active state based on scroll position
6. Takes into account header height and admin toolbar displacement

## CSS Features

- Sticky positioning for the block container
- Visual active state for current section
- Left border accent styling
- Responsive typography
- CSS custom properties for theming

## Notes

- The component automatically excludes h2 elements within `.table-of-contents` to avoid recursion
- IDs are generated by converting heading text to lowercase, removing special characters, and replacing spaces with dashes
- The sticky position is set at `top: 220px` in the parent paragraph container
- Active navigation links are highlighted with color change and thicker left border
